# Janhyangguk asset layout

Runtime/game assets use `assets/` as the single canonical root.

- `assets/cutscenes/` — opening and cutscene images / expression payloads
- `assets/employees/` — employee SD assets
- `assets/anomalies/` — anomaly assets and manifests

Do not add new runtime assets under root, `resources/`, or `dist/assets/`; merge them here instead.
