# 잔향국 게임 고도화 계획 vNext

> 기준일: 2026-09-23  
> 목표: 기능을 늘리기 전에 **DAY 1의 관리 루프를 처음부터 끝까지 실제로 플레이 가능하게 만들고**, 이후 복수 격실·잔향·직원 손실 누적으로 확장한다.

## 1. 코어 플레이 루프

정본 루프는 아래 순서다.

`격실 확인 → 작업 선택 → 직원 직접 선택 → 이동 → 작업 → 관찰 → 전조 → 판단(관찰 유지/철수) → 결과 → 귀환 → 기록/후유증 반영 → 다음 작업 → DAY 정산`

핵심 원칙:

- 직원은 자동 추천/자동 배치하지 않는다.
- 이동과 작업은 실제 시간이 흐른다.
- 작업 도중 플레이어가 잔향과 직원 상태를 관찰한다.
- 결과가 바로 뜨는 버튼형 관리가 아니라, **작업 중 판단**이 핵심이다.
- 초기 2회 관리는 DAY 1 안전 잠금을 적용해 치명적 손실을 막는다.
- DAY 1에는 대형 MELTDOWN을 강제하지 않는다.

## 2. 2026-09-23 적용 완료

현재 `management/index.html`에 다음을 반영한다.

- DAY 1 목표: 안전 관리 3회
- 작업 선택: 관찰 / 안정화 / 교감 / 억제
- 직원 직접 선택 및 이동 ETA
- 직원 이동 → 작업 → 귀환 상태 전이
- 작업별 실제 진행 시간
- 직원 HP / SP / 피로 / 경험 표시 및 누적
- 첫 관리에서 기준 관찰과 과거 기록의 불일치 발견
- 두 번째 관리 이후 OMEN 전조 발생
- OMEN 시 작업 시간을 멈추고 `관찰 유지 / 철수`를 직접 선택
- 관찰 유지 시 관찰 정보와 잔류 반응이 증가
- 철수 시 작업을 중단하고 직원이 실제로 귀환
- NORMAL / OMEN / UNSTABLE / RECOVERY 표시
- 기록 파편 복원 및 대조/추정 정보
- DAY 01 목표 달성 후 정산 화면
- 최소 WebAudio 경고/문/완료 사운드
- 실제 아트가 생기면 자동으로 연결되는 경로 로더
  - 잔향 작업용 2D: `assets/anomalies/one-stroke/work/one-stroke_{state}.png`
  - 직원 SD: `assets/employees/{employee}/{idle|walk|work}/{employee}_{state}_NN.png`
- 아트가 아직 없으면 기존 CSS 임시 표현으로 안전하게 폴백

## 3. 다음 고도화 순서

### M1. DAY 1 비주얼 완성

필요 자산:

- `한 획` 작업용 2D NORMAL
- `한 획` 작업용 2D OMEN
- 필요 시 UNSTABLE
- DAY 1 출전 직원 SD `idle / walk / work`

완료 기준: CSS 임시 캐릭터/격실 없이 실제 제작 아트로 DAY 1을 끝까지 플레이할 수 있다.

### M2. DAY 1 체감 강화

- 실제 BGM
- 문 개폐 / 발걸음 / 작업 장비 / 전조 / 경고 사운드
- 작업별 서로 다른 작업 모션과 피드백
- DAY 시작/종료 연출
- 결과보다 전조를 먼저 느끼게 하는 화면/음향 연출

### M3. 잔향 3종 관리

- 잔향 3종의 관리 규칙 확정
- 각 잔향마다 `평상시 → 전조 → 판단 → 결과` 구조
- 잔향별 판단 포인트는 1~3개로 제한
- 도감용 일러스트와 작업용 2D를 분리

### M4. 복수 격실 동시 관제

- 2~3개 격실을 동시에 운영
- 직원 이동/작업 상태를 한눈에 확인
- 전조가 겹쳐 발생할 수 있음
- 플레이어가 우선순위를 직접 판단

### M5. 누적 손실과 캠페인

- 부상
- 정신 불안정
- 피로
- 격리/실종/사망 등 후속 상태
- 직원 경험과 잔향 정보 해금
- DAY 간 상태 유지

## 4. 현재 부족 요소

### 아트 자산 부족

현재 저장소에 실제 직원 SD 세트와 `한 획` 작업용 2D 정본이 아직 없으면 관리 화면은 CSS 폴백을 사용한다. 아래 자산이 생성되는 즉시 코드 수정 없이 자동 연결되도록 구현한다.

```text
assets/anomalies/one-stroke/work/
  one-stroke_normal.png
  one-stroke_omen.png
  one-stroke_unstable.png

assets/employees/hajin/idle/
assets/employees/hajin/walk/
assets/employees/hajin/work/
...
```

### DAY 02 콘텐츠 미확정

DAY 01 정산 화면까지는 구현하되, DAY 02는 신규 잔향·복수 격실·스토리 순서가 확정되기 전 임의로 만들지 않는다.

### 도감 전용 화면 미구현

잔향 도감용 일러스트가 확보된 뒤 별도 화면으로 연결한다. 현재 하단 `도감` 버튼은 준비 상태만 알린다.

## 5. 다음 검증 질문
